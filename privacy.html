Terms of ServicePrivacy Policy

Information handled

Terrace Clips receives an access token and a refresh token from TikTok when the operator authorises it for @sunrise.terrace, limited to the permission to upload video. No password, no profile data, no audience data and no content from any other user is received.

Purpose

The token exists so the tool can place the operator's own clips in the operator's own drafts. Nothing else is done with it and nothing further is read from the account.

Where it lives

In a single file on the operator's computer, protected by that computer's file permissions. It is not sent to a server, not backed up to a cloud service by the tool, and not disclosed to anyone.

Sharing with others

There is none. The tool and this page use no analytics, advertising, or tracking of any kind.

Keeping and removing it

The token is kept until the operator removes the file or revokes the app from TikTok's connected apps settings, which cuts off access immediately. Drafts and posts on TikTok are governed by TikTok's terms.

About this page

Static HTML. No cookies, no scripts, no visitor records.

Contact

Questions about Terrace Clips: a message to @sunrise.terrace on TikTok.
